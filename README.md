# КурсМетр

Веб-приложение для анализа рынка квартир и ориентировочной оценки стоимости
недвижимости в Курске. Пользователь выбирает адрес дома и задаёт параметры
квартиры, после чего модель рассчитывает стоимость, цену квадратного метра,
диапазон неопределённости и показывает метрики на отложенной выборке.

**Демонстрация:** [kurskmetr.online](https://kurskmetr.online)

![Интерфейс КурсМетра](public/og.png)

## Возможности

- встроенный снимок из 250 публичных объявлений по Курску;
- 133 адреса и жилых комплекса с автодополнением;
- учёт площади, комнат, этажа, этажности, округа и типа рынка;
- учёт года и типа постройки, индивидуального отопления и отделки;
- Ridge-регрессия, обучаемая непосредственно в браузере;
- адресные аналоги: тот же дом, затем округ и тип рынка;
- прозрачные сценарные корректировки характеристик с отображением их вклада;
- расчёт R², MAE и RMSE на отложенной выборке;
- отдельный Python-пайплайн со `scikit-learn` для экспериментов.

## Технологии

- Next.js 16, React 19 и TypeScript;
- Tailwind CSS/PostCSS;
- клиентская реализация Ridge-регрессии;
- Python, pandas и scikit-learn для офлайн-обучения.

## Как устроена модель

Веб-приложение делит датасет детерминированно: каждая пятая строка попадает
в тестовую часть, остальные строки используются для обучения. Числовые
признаки стандартизируются, категории кодируются бинарно, а коэффициенты
Ridge-регрессии рассчитываются решением системы линейных уравнений.

Используются следующие признаки:

- площадь и количество комнат;
- относительный этаж и этажность дома;
- ориентир цены квадратного метра по адресу или району;
- округ Курска;
- новостройка или вторичный рынок.

После базового прогноза применяются отдельные сценарные корректировки по
году постройки, конструкции дома, наличию индивидуального отопления и уровню
отделки (`без отделки`, `white box` или ремонт). Для квартир с ремонтом
дополнительно учитывается его класс: эконом, комфорт или бизнес. Эти поля
отсутствуют в исходном снимке объявлений, поэтому приложение не выдаёт их за
обученные признаки: величина каждой корректировки явно показывается
пользователю в процентах и рублях.

Скрипт `ml/train_model.py` представляет отдельный эксперимент: он обучает
`RandomForestRegressor` с обработкой числовых и категориальных признаков,
выводит метрики и сохраняет модель в `ml/artifacts/model.joblib`.

## Датасет

Файл: `data/kursk_apartments_cian_snapshot.json`.

Снимок собран 30.07.2026 по публичным страницам объявлений ЦИАН:

- [1-комнатные квартиры](https://kursk.cian.ru/kupit-1-komnatnuyu-kvartiru/);
- [2-комнатные квартиры](https://kursk.cian.ru/kupit-2-komnatnuyu-kvartiru/);
- [3-комнатные квартиры](https://kursk.cian.ru/kupit-3-komnatnuyu-kvartiru/).

В данных находятся цены предложений, а не цены завершённых сделок.
Персональные данные продавцов не сохраняются. ЦИАН не связан с проектом.

Каждая строка JSON содержит:

| Позиция | Поле | Описание |
| --- | --- | --- |
| 1 | `listing_id` | Идентификатор объявления |
| 2 | `address` | Адрес дома |
| 3 | `district` | Округ Курска |
| 4 | `listing_kind` | Вторичка или новостройка |
| 5 | `rooms` | Количество комнат |
| 6 | `area` | Общая площадь, м² |
| 7 | `floor` | Этаж квартиры |
| 8 | `total_floors` | Этажность дома |
| 9 | `price` | Цена предложения, ₽ |

## Локальный запуск

Понадобятся Node.js 22+ и pnpm.

```bash
corepack enable
pnpm install
pnpm dev
```

Откройте [http://localhost:3000](http://localhost:3000).

Production-сборка:

```bash
pnpm build
pnpm start
```

Проверка проекта:

```bash
pnpm check
```

## Запуск Python-модели

```bash
python -m venv .venv
python -m pip install -r ml/requirements.txt
python ml/train_model.py
```

Другой JSON или CSV можно передать явно:

```bash
python ml/train_model.py --data path/to/apartments.csv
```

## Ограничения

Результат носит исследовательский характер. Датасет отражает состояние
публичных объявлений на конкретную дату, а рассчитанная стоимость не заменяет
отчёт профессионального оценщика и не гарантирует цену сделки.
