# КурсМетр

Веб-приложение для анализа рынка квартир и ориентировочной оценки стоимости
недвижимости в Курске. Пользователь выбирает адрес дома и задаёт параметры
квартиры, после чего модель рассчитывает стоимость, цену квадратного метра,
диапазон неопределённости и показывает метрики на отложенной выборке.

**Демонстрация:** [kursk-city.vercel.app](https://kursk-city.vercel.app/)


![Интерфейс КурсМетра](public/og.png)

## Возможности

- встроенный снимок из 250 публичных объявлений по Курску;
- 133 адреса и жилых комплекса с автодополнением;
- учёт площади, комнат, этажа, этажности, округа и типа рынка;
- год и тип постройки, отопление, отделка и класс ремонта входят в ML;
- Ridge-регрессия, обучаемая непосредственно в браузере;
- адресные аналоги: тот же дом, затем округ и тип рынка;
- отображение вклада наиболее значимых признаков модели;
- расчёт R², MAE и RMSE на отложенной выборке;
- отдельный Python-пайплайн со `scikit-learn` для экспериментов.

## Технологии

- Next.js 16, React 19 и TypeScript;
- Tailwind CSS/PostCSS;
- клиентская реализация Ridge-регрессии;
- Python, pandas и scikit-learn для офлайн-обучения.

## Как устроена модель

Веб-приложение делит датасет детерминированно: каждая пятая строка попадает
в тестовую часть, остальные строки используются для обучения. Числовые
признаки стандартизируются, категории кодируются бинарно, а коэффициенты
Ridge-регрессии рассчитываются решением системы линейных уравнений.

Используются следующие признаки:

- площадь и количество комнат;
- относительный этаж и этажность дома;
- ориентир цены квадратного метра по адресу или району;
- округ Курска;
- новостройка или вторичный рынок.
- год постройки;
- материал/конструкция дома;
- наличие поквартирного индивидуального отопления;
- отделка (`без отделки`, `white box` или `с ремонтом`);
- класс ремонта (`эконом`, `комфорт` или `бизнес`).

Ручных процентных надбавок к прогнозу нет. Все перечисленные характеристики
кодируются в вектор признаков и участвуют в расчёте коэффициентов Ridge.
Модель прогнозирует цену квадратного метра, после чего умножает её на площадь
квартиры. Уровень ремонта кодируется как упорядоченный признак
`эконом < комфорт < бизнес`, поэтому более высокий класс не может случайно
оказаться ниже предыдущего из-за редкой категории. Расширенные признаки
регуляризуются сильнее базовых, чтобы единичные объявления не давали
нереалистично большой вклад.
Неуказанные категории получают отдельный индикатор «не указано», а пропуск
года заполняется медианой вместе с отдельным индикатором пропуска. Поэтому
неполные объявления остаются в выборке, но отсутствующие значения не
подменяются придуманными характеристиками.

Скрипт `ml/train_model.py` представляет отдельный эксперимент: он обучает
`RandomForestRegressor` с обработкой числовых и категориальных признаков,
выводит метрики и сохраняет модель в `ml/artifacts/model.joblib`.

## Датасет

Основной файл модели:
`data/kursk_apartments_enriched_all.json`.

Исходный компактный снимок сохранён в
`data/kursk_apartments_cian_snapshot.json`, а отчёт о заполненности находится
в `data/kursk_apartments_enrichment_report.json`.

Снимок собран 30.07.2026 по публичным страницам объявлений ЦИАН:

- [1-комнатные квартиры](https://kursk.cian.ru/kupit-1-komnatnuyu-kvartiru/);
- [2-комнатные квартиры](https://kursk.cian.ru/kupit-2-komnatnuyu-kvartiru/);
- [3-комнатные квартиры](https://kursk.cian.ru/kupit-3-komnatnuyu-kvartiru/).

В данных находятся цены предложений, а не цены завершённых сделок.
Персональные данные продавцов не сохраняются. ЦИАН не связан с проектом.

Каждый объект расширенного JSON содержит:

| Поле | Описание |
| --- | --- |
| `id` | Идентификатор объявления |
| `address` | Адрес дома |
| `district` | Округ Курска |
| `listingKind` | Вторичка или новостройка |
| `rooms` | Количество комнат |
| `area` | Общая площадь, м² |
| `floor` | Этаж квартиры |
| `totalFloors` | Этажность дома |
| `buildingYear` | Год постройки/сдачи |
| `buildingType` | Тип конструкции дома |
| `individualHeating` | Поквартирное индивидуальное отопление |
| `finishType` | Вид отделки |
| `repairClass` | Класс ремонта |
| `price` | Цена предложения, ₽ |
| `sourceUrl` | Публичная страница источника |
| `provenance` | Происхождение расширенных значений |

Заполненность расширенных полей:

| Поле | Заполнено |
| --- | ---: |
| Год постройки | 246 из 250 |
| Тип дома | 216 из 250 |
| Индивидуальное отопление | 121 из 250 |
| Отделка | 230 из 250 |

Некоторые редкие категории представлены малым числом примеров. В частности,
выбор варианта, отсутствующего в обучающей части, не должен интерпретироваться
как статистически подтверждённая надбавка или скидка.

## Локальный запуск

Понадобятся Node.js 22+ и pnpm.

```bash
corepack enable
pnpm install
pnpm dev
```

Откройте [http://localhost:3000](http://localhost:3000).

Production-сборка:

```bash
pnpm build
pnpm start
```

Проверка проекта:

```bash
pnpm check
```

## Запуск Python-модели

```bash
python -m venv .venv
python -m pip install -r ml/requirements.txt
python ml/train_model.py
```

Другой JSON или CSV можно передать явно:

```bash
python ml/train_model.py --data path/to/apartments.csv
```

## Ограничения

Результат носит исследовательский характер. Датасет отражает состояние
публичных объявлений на конкретную дату, а рассчитанная стоимость не заменяет
отчёт профессионального оценщика и не гарантирует цену сделки.
